Запомни: объект

  • Объект — всё, что можно назвать и рассмотреть отдельно.
  • Общее имя — для целой группы: кот, река. Собственное — для одного объекта, с большой буквы: Барсик, Волга.

Бонус-остров

Справился быстро? Тогда для тебя открыт тайный остров: ещё 3 уровня и 3 алмаза. Здесь объекты начинают дружить, собираться в системы, а в конце ты разберёшь по частям сам компьютер.

Запомни: отношения объектов

  • Состоит из — объект собран из частей: велосипед состоит из колёс, руля и рамы. Часть и целое.
  • Является разновидностью — объект входит в более широкую группу: берёза является разновидностью дерева. Вид и группа.
  • Проверка: можно ли сказать «… — это часть …»? Значит, «состоит из». Можно сказать «… — это вид …»? Значит, «разновидность».

Запомни: системы

  • Система — целое, которое состоит из частей, связанных между собой. Велосипед, футбольная команда, компьютер — системы.
  • Если убрать важную часть или перемешать части, система перестанет работать.
  • Системный эффект — то, что умеет целое, но не умеет ни одна часть по отдельности. Колесо само не поедет, руль тоже, а велосипед едет.

Запомни: компьютер как система

  • Железо (аппаратное обеспечение) — устройства, которые можно потрогать. Софт (программное обеспечение) — программы, их потрогать нельзя.
  • Ввод — передают информацию в компьютер: клавиатура, мышь, микрофон. Вывод — выдают её нам: монитор, колонки, принтер.
  • Обработка — процессор, «мозг» компьютера. Хранение — память: жёсткий диск, флешка.
  • Системный эффект компьютера: железо без программ ничего не делает, программы без железа не запустятся. Вместе они работают.
